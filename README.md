TinyFn provides a suite of over 500 deterministic Model Context Protocol (MCP) tools for AI agents, covering math, timezone conversion, input validation, statistics, hashing, encoding, unit conversion, string manipulation, date/time calculations, color utilities, JSON processing and more. These utilities are offered via a RESTful API designed for seamless integration into AI workflows, enabling reliable, repeatable operations without external dependencies.

**Areas:** AI · Tools · Deterministic · MCP · Utilities

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for TinyFn: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
